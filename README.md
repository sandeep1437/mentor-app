# GW Mentor — Mobile App (Flutter)

A cross-platform Flutter mobile application designed for multi-persona technical documentation and interactive diagrams.

### Running the App:
1. `flutter pub get`
2. `flutter run` (on your Android device, emulator, or iOS simulator)

### Build APK:
```bash
flutter build apk --release
```
Output: `build/app/outputs/flutter-apk/app-release.apk`
